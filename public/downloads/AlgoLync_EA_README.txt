ALGOLYNX MT5 INSTALLATION
========================

1. Download the compiled .ex5 file from your authenticated /portal workspace.
2. Download MacroLyncLicense.mqh from the same authorized workspace.
3. Place the .ex5 file in MQL5/Experts/ and the .mqh include in MQL5/Include/.
4. Open the authenticated /portal workspace for the private MT5 WebRequest allowlist and setup checklist.
5. In the EA inputs, enter your license key and the exact EA product slug shown in your subscription.
6. Attach the EA to the chart. The Cloud Gate verifies the MT5 account mode, login, EA entitlement and subscription status.

Never paste API keys or broker passwords into the EA. The public .mq5 source is reserved for the free MacroLync G10 ATR Breakout sandbox.
